Compatibility

A platform or harness is supported only after the packaged artifact passes the canonical end-to-end proof on the named native runner and pinned host version.

SurfaceVerified local evidenceHeld before support
macOS arm64Full npm/Python SDK facades, exact native companions, auth-enabled manager and engine candidate, real stdio MCP, account refusal, clean install/update/rollback/uninstall, vault canary, and real Codex CLI configuration.Production signature/notarization, approved terms, live OIDC/keychain, model/TUI/IDE acceptance, and protected publication.
macOS x64Target metadata/refusal only.Native binaries, package, runner, signing/notarization.
Linux x86_64/arm64Source implementation and target metadata only; libc policy not frozen.Native credential store, binaries, packages, runners, installer evidence.
Windows x86_64/arm64Source implementation and target metadata only.Native credential store, binaries, packages, runners, installer evidence.
CodexConfig transforms plus real pinned CLI add/list/get/remove and exact isolated rollback.Model/TUI acceptance and a protected published install.
Claude Code / Cursor / OpenCodeConfig render, dry run, idempotence, and exact rollback.Installed CLIs/IDE and pinned live-host acceptance.
Framework clientsGeneric MCP and adapter lifecycle suites passed with pinned versions and final-candidate non-auth conformance.Live-provider lanes where required and protected published packages.

Cross-compiling, extracting a foreign package, parsing configuration, or running a fake provider is useful evidence but not native support. Nothing in this table is a public availability claim.
