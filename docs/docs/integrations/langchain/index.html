LangChain integration

Use the official LangChain MCP adapter to load the two Kaleidoscope tools inside one adapter session. Kaleidoscope is not a BaseStore implementation.

Lifecycle

Open the stdio adapter once around the application’s intended agent run, load and filter the two tools, then close the adapter after the run. The application supplies its model-provider credentials separately.

Boundary

Do not implement a parallel LangChain memory or summarize messages into a second store. The MCP server remains the one canonical memory owner.

Evidence boundary

The pinned local LangChain adapter suite verified remembered and searched values share one MCP process. It uses a deterministic provider double and does not claim live provider behavior.
