Cursor integration

Cursor uses the same local MCP command and only the two public memory tools. The manager makes the JSON mutation reversible and adds a small project rule only when requested.

Connect and guide

kaleidoscope connect cursor --profile default --project "$PWD" --dry-run
kaleidoscope connect cursor --profile default --project "$PWD"
kaleidoscope instructions install cursor --project "$PWD"

Existing unrelated entries stay untouched. Tampered receipts, conflicting names, malformed configuration, symlinked files, and concurrent edits are refused for manual review.
