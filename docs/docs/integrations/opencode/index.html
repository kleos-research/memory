OpenCode integration

OpenCode stable v1 and beta v2 use different configuration shapes. Kaleidoscope never guesses or silently migrates between them.

Stable v1 by default

kaleidoscope connect opencode --profile default --project "$PWD" --dry-run
kaleidoscope connect opencode --profile default --project "$PWD"

Explicit beta v2

kaleidoscope connect opencode --profile default --project "$PWD" --opencode-version beta-v2 --dry-run

The stable entry is a direct local command; beta v2 uses the explicit server shape with code mode disabled so search and remember remain visible. Ambiguous dual shapes are refused.

Evidence boundary

Both renderers and safe mutation paths passed locally. Installed OpenCode acceptance remains held.
