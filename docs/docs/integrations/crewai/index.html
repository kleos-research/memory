CrewAI integration

CrewAI uses one stdio MCP adapter context for the crew run. The adapter exposes only the Kaleidoscope tools that are appropriate for the model.

Lifecycle

Construct the adapter with the manager-generated local descriptor, enter it once, select search and remember, run the crew, then close the context. Do not recreate the server for each task.

Boundary

The framework owns provider configuration and crew state. Kaleidoscope owns only its local memory and does not receive model-provider credentials or account tokens.

Evidence boundary

The pinned adapter was exercised against the local MCP fixture with one persistent process and explicit tool filtering.
