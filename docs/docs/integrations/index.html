Agent and framework integrations

Find your editor or framework below, then follow its page for the exact commands. Whatever you connect, it talks to the one engine on your machine and sees exactly two tools, search and remember — so every tool you connect shares the same memory instead of starting a store of its own.

“Tested” means we have run it ourselves on a Mac with Apple Silicon and it worked. “Partly tested” means part of it has been run and part has not; the limitation column says which part. Neither word means released or supported — the full definitions are on Platform support.

IntegrationStatusLimitationHow you connect
CodexPartly testedIts configuration is written and removed exactly, but Codex gives no way to confirm it then started the serverkaleidoscope connect codex

Claude Agent SDKPartly testedRun against a stand-in model, never against a live providerThe SDK’s own stdio MCP configuration
OpenAI Agents SDKPartly testedRun against a scripted model, never against a live providerThe SDK’s stdio MCP server lifecycle
CrewAIPartly testedRun against a local test server, never against a live providerThe CrewAI MCP adapter context

The editor versions we tested against were Codex 0.149.0, Claude Code 2.1.239, and OpenCode 1.18.21. None of this installs from a registry yet, so connecting an editor means pointing it at a build you already have on your machine.

Integration pages

  • Editors and CLIsCodex — one entry in Codex’s own configuration, removable byte for byte; Claude Code — one entry in .mcp.json; Cursor — one entry in mcp.json plus an optional project rule; OpenCode — stable v1 by default, beta v2 only when you ask.
  • Direct MCPPython and TypeScript generic MCP — the launch descriptor any standard MCP client can read, over one long-lived process.
  • Agent frameworksClaude Agent SDK — one client, two allowed tool names; LangChain and LangGraph — one session, no second memory store; OpenAI Agents SDK — Python and TypeScript; CrewAI — one adapter context for the crew run.

Telling your agent about it

Install the public skill, then add the short pointer that fits your project — AGENTS.md, CLAUDE.md, or the Cursor rule. Make the change with kaleidoscope rather than by hand, so you keep the dry run, the backup, and exact removal.
