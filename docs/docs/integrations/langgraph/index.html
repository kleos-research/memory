LangGraph integration

LangGraph uses the same one-session MCP adapter as LangChain, placed in the graph’s tool node for the run.

Boundary

Kaleidoscope is not a LangGraph checkpointer or BaseStore. Graph state and local durable memory remain distinct so the integration does not create a second canonical owner.

Lifecycle

Open the adapter before executing the graph, pass the filtered MCP tools into the tool node, and close it once execution is complete. Reuse the session across node calls.

Evidence boundary

The pinned local graph test exercised a tool node calling remember then search through the same MCP process.
