0.1.0-rc.1 · a2357ed6c00e

Getting started

The verified manager creates or imports one local profile, previews an owner-marked host change, applies it with confirmation, and can remove exactly what it owns.

Release-candidate quickstart, not a live registry command. The converged 0.1.0-rc.1 package contract passed locally for macOS arm64, but the packages remain private, test-signed, unpublished, and unavailable from public registries.

1. Install after protected promotion

Choose one public SDK facade after publication. Each facade installs its exact macOS arm64 native companion; do not install both and do not omit the native dependency.

# npm / Node.js 22+
npm install -g @kleos-research/kaleidoscope@0.1.0-rc.1

# or Python 3.11+
python -m pip install kaleidoscope-memory==0.1.0rc1

kaleidoscope --version
kscope --version

The facade contains the full public SDK, installed-payload resolver, and both launchers. Its native companion contains the manager and proprietary object-code engine without engine source. There is no install hook, runtime download, compiler, or source-build fallback.

2. Initialize a profile

kaleidoscope init   --profile default   --root /absolute/path/to/user-owned/kaleidoscope-memory
kaleidoscope config --profile default --json

The launcher resolves the manager and engine from the installed native companion. A profile is selected through the manager and native profile registry; agent configuration receives mcp --profile NAME, not credentials or raw vault coordinates.

3. Preview and connect a host

kaleidoscope connect codex --profile default --project "$PWD" --dry-run
kaleidoscope connect codex --profile default --project "$PWD"
kaleidoscope doctor --project "$PWD"

Local tests cover codex, claude, cursor, and opencode transforms. In addition, platform-harness commit 52ad4d2… exercised pinned Codex 0.149.0, Claude Code 2.1.239, and OpenCode 1.18.21 CLI wiring on macOS arm64 against a model-absent development binary; it verified local connection and stdio discovery of exactly search and remember. This is not released-package, credentialed-model, GUI/IDE, Cursor, or production acceptance. Existing unrelated configuration is preserved; ambiguous, symlinked, tampered, or concurrently edited files are refused.

4. Verify the contract

The local candidate contract is bound to engine SHA-256 988192ac9677… and public-contract SHA-256 a2357ed6c00e…. It publishes exactly remember and search; the launch descriptor presents the agent-facing order search, remember. Ranked search returns selected_hits; addressed search returns the memory at top level.

5. Disconnect safely

kaleidoscope disconnect codex --project "$PWD" --dry-run
kaleidoscope disconnect codex --project "$PWD"

Disconnect removes only Kaleidoscope-owned material and leaves other host settings and vault bytes unchanged.
