Kaleidoscope documentation

Local memory for agents · CLI and stdio MCP · macOS on Apple Silicon

Kaleidoscope is local memory for agents. Your memory lives in a vault on your machine, and every editor or agent you connect shares one profile through a CLI and a long-lived MCP server.

Kaleidoscope is not released. You cannot install it from npm or PyPI, you cannot sign in, and there is no public source repository for the clients yet. What works today lists what has actually been run, and on what.
