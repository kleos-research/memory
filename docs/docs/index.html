Kaleidoscope documentation

Kaleidoscope is local memory for agents: a native CLI and persistent stdio MCP server with one profile shared across configured harnesses.

Release status. This is a non-indexable documentation staging build. Local implementation and conformance evidence exists, but no package, registry, production login, public SDK repository, or Pages promotion is authorized.

Choose a path

  • Agent user: read Getting started; the commands are an interface preview until a protected release is approved.
  • Application developer: begin with Integrations, then use the persistent MCP contract.
  • Operator: use Operations for separate configuration, credential, package, and vault lifecycles.
  • Security or privacy reviewer: read Security, Privacy, and the machine-readable staging evidence.
  • Agent crawler: start at llms.txt or the expanded llms-full.txt.
