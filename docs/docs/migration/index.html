0.1.0-rc.1 · a2357ed6c00e

Migration from historical tool contracts

Current agents discover exactly search and remember. Historical names are not aliases and must be removed from host allowlists and prompts.

Retrieval

Replace recall, compile, and read_memory with search. Send query for ranked retrieval and memory_id for an addressed read. Ranked results are under selected_hits. Use top_k, not limit.

Writing

Replace ingest_memory or prose-inference paths with explicit remember semantic deltas. The runtime does not infer entities, facts, relationships, or dates from prose.

Other retired names

Remove merge_verdict, ontology_proposal, policy, policy_patch, ope, and replay from agent definitions. The generated candidate contract marks them retired.

Operator feedback

feedback is an operator command, not an MCP tool. Public search does not return its required decision handle, so a model has no supported public path to call it. Do not reconstruct private state or advertise a fake attribution workflow.
